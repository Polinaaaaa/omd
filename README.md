# omd

ДЗ 1 по Основам языка Python

## Содержимое проекта
`1.py`, `2.py`, `3.py`, `4.py`, `5.py`- задания 1-5 соответственно темы Основы языка Python

## Требования

- Python 3.8 или новее
- Сторонние библиотеки не используются

## Установка зависимостей

Внешних зависимостей нет

## Запуск

Каждый из скриптов можно запустить отдельно в проекте:

```bash
python 1.py
python 2.py
python 3.py
python 4.py
python 5.py
```

Если команда не работает, то можно использовать `python3`:

```bash
python3 1.py
python3 2.py
python3 3.py
python3 4.py
python3 5.py
```

Результат отображается в консоли.

ДЗ 2 Функции

## Содержимое проекта
Папка Дз2 Функции:
`import csv.py`, `output_file.csv`, `Corp_Summary-4i5r1ko1np8o7qyphd7tngu7io.csv` -  код задания, файл результата для третьего пункта, файл с исходными данными

## Данные
В `Corp_Summary-4i5r1ko1np8o7qyphd7tngu7io.csv` лежит выгрузка по сотрудникам: ФИО, департамент, команда, должность, оценка, оклад. Колонки разделены `;`.
Данные читаются из этого файла и по ним строится 3 типа отчетов по выбору. 
Используется import csv.


## Требования

- Python 3.8 или новее
- Сторонняя библиотеки не используется
- Используется import csv

## Установка зависимостей

Внешних зависимостей нет

## Запуск

```bash
python main.py <номер варианта 1-3 >
```

или 

```bash
python3 main.py <номер варианта 1-3 >
```

Результат отображается в консоли в 1, 2 отчетах. Третий отчет записывает результат в новый файл output_file.csv.
