# omd

ДЗ 1 по Основам языка Python

## Содержимое проекта
`1.py`, `2.py`, `3.py`, `4.py`, `5.py`- задания 1-5 соответственно темы Основы языка Python

## Требования

- Python 3.8 или новее
- Сторонние библиотеки не используются

## Установка зависимостей

Внешних зависимостей нет

## Запуск

Каждый из скриптов можно запустить отдельно в проекте:

```bash
python 1.py
python 2.py
python 3.py
python 4.py
python 5.py
```

Если команда не работает, то можно использовать `python3`:

```bash
python3 1.py
python3 2.py
python3 3.py
python3 4.py
python3 5.py
```

Результат отображается в консоли.
